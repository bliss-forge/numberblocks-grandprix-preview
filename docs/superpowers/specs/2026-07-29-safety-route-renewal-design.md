# 안전한 길찾기 전면 리뉴얼

## 목표

두 동네 안전길 지도를 실제 동네처럼 보이게 다시 그리고, 목적지(학교)의
가시성과 안전 행동 학습 연출을 강화한다. 게임 규칙 골격은 유지한다.

완료 기준은 다음과 같다.

- 두 동네가 빈 들판이 아니라 건물·소품이 채워진 동네로 보인다.
- 건물은 잔디 위 간판이 아니라 여러 칸을 차지하는 정면 뷰 블록이다.
- 학교는 지도에서 가장 큰 랜드마크이고, 골인 지점이 한눈에 보인다.
- 미니맵으로 내 위치·다음 친구·학교·신호 상태를 항상 알 수 있다.
- 신호등·자동차·킥보드·자전거·공사장·맨홀·횡단보도가 모두 새 일관된
  플랫 벡터 스타일로 그려지고 배치가 자연스럽다.
- 초록불 횡단 시 멈춤→좌우 살피기→손 들고 건너기 연출과 음성이 나온다.
- 기존 이동 규칙·경로 검증·신호 주기·랜덤 배치가 그대로 동작한다.

## 유지 범위 (변경 금지)

- 32×16 그리드와 `왼동네 14 | 도로 4 | 오른동네 14` 구역 비율
- 친구 2→10 순서 수집 후 학교 도착, 2~5를 만나기 전 도로 횡단 금지
- 신호 주기 `vehicle-go 5s → clearance 1s → pedestrian-go 7s → clearance 1s`,
  보행 초록불 종료 2초 전 신규 횡단 금지
- 충돌·감점·게임 오버 없음, 이동체는 플레이어 칸에 진입하지 않음
- 화살표/WASD 이동, 140ms 반복 간격, 방향 버튼 패드
- 후보 슬롯 랜덤 배치 + 경로 검증(20회 재시도 후 고정 배치) + 시드 유지
- 난이도 3종(쉬움/차근차근/도전)별 장애물 수
- 기존 한국어·영어 음성 체계와 효과음 구조

## 시각 시스템

### 건물과 동네

잔디 칸은 원래 이동 불가이므로 건물 풋프린트는 충돌 로직 변경 없이 잔디
영역에 배치한다. 모든 건물은 정면 뷰(지붕·정면·문·창문)이고 흰 외곽선과
파스텔 색으로 그린다. 간판은 건물 상단에 붙인다.

- 왼동네: 우리 집(2×2), 어린이집(2×2), 상가(3×2), 공원(2×2 — 나무·벤치
  중심의 열린 공간)
- 오른동네: 도서관(2×2), 정류장(1×2 + 버스 표지판), 가게(2×2), 학교(3×3)
- 건물 문은 보행길을 향하고, 문 앞 보행길 칸이 친구 후보 칸이 된다.
- 남는 잔디에는 나무·꽃밭·벤치·화단 소품을 밀도 있게 배치한다.

### 학교 랜드마크와 골인 지점

- 학교는 지도 최대 크기(3×3칸)로, 붉은 지붕 + 시계탑 + 깃발 + 노란 정문.
- 정문 앞 보행길 칸이 골인 칸이며 `⭐ 도착` 매트로 표시한다.
- 도착 시 폭죽·별 연출과 축하 음성을 재생한다.
- 학교가 화면 밖이면 기존 가장자리 화살표에 학교 아이콘을 함께 표시한다.

### 도로부

- 아스팔트 질감(어두운 회색 + 미세 노이즈), 중앙 노란 점선, 차선별 진행
  방향 화살표.
- 횡단보도는 흰 줄무늬 + 양쪽 정지선. 기존 2곳(위·아래) 유지.
- 신호등은 각 횡단보도 진입부 양끝 모서리에 보행자 신호등(사람 아이콘,
  빨강/초록) 한 쌍만 둔다. 기존 보도 위 신호등 4개는 제거한다.
- 자동차는 3/4 뷰로 차체·지붕·앞유리·헤드라이트·네 바퀴가 보이게 그리고,
  북행/남행 진행 방향에 맞춰 회전한다. 정지선 앞 정지 동작은 유지한다.

### 라이더 (킥보드·자전거)

- 브레인스토밍 v2 목업의 인라인 SVG를 기반으로 구현한다.
- 자전거: 두꺼운 타이어+스포크 바퀴 2개, 다이아몬드 프레임, 갈색 안장·
  손잡이, 크랭크·페달, 헬멧 쓴 아이가 앞으로 숙여 페달 밟는 자세.
- 킥보드: 데크+스템+손잡이+작은 바퀴 2개, 아이가 서서 타는 자세.
- 진행 방향에 따라 좌우 반전, 이동 중 바퀴 회전 + 미세한 상하 흔들림.
- `prefers-reduced-motion`에서는 회전·흔들림을 끄고 위치 변화만 유지한다.
- 순찰 구간은 친구 후보 칸·건물 문 앞 칸·횡단보도와 겹치지 않도록
  레이아웃 데이터에서 재정의한다. 정지·반전 규칙(0.6초)은 유지한다.

### 공사장과 맨홀

- 공사장: 골목 입구·출구에 주황/흰 사선 펜스, 사이에 노란 포크레인(캡·
  트랙·암·버킷)과 `🚧 공사중` 표지판. 골목 전체 줄무늬 타일은 제거한다.
- 맨홀: 어두운 구멍(내부 격자) + 옆에 비스듬히 열린 뚜껑 + 주의 고깔 1개.
- 두 장애물 모두 흰 외곽선과 높은 대비를 유지하고 충돌 판정 칸은 바꾸지
  않는다.

## 신규 기능

### 미니맵

- 위치: 우상단 고정(사운드 버튼 아래). 데스크톱 240×130px, 모바일 150px.
- 내용: 두 동네+도로+보행길 실루엣, 내 위치(빨강 점), 다음 친구(노랑 점,
  깜빡임), 학교(아이콘), 현재 보행 신호 상태.
- 상호작용 없음(표시 전용). 레이아웃 데이터에서 파생 렌더링한다.

### 시작 카메라 투어

- 게임 시작 시 카메라가 집→(보행길 경로 방향)→학교를 약 3초간 팬하고
  플레이어로 돌아온다. "학교까지 안전하게 가 보자!" 음성을 함께 재생한다.
- 아무 키나 누르면 즉시 생략하고 플레이어 중심으로 복귀한다.
- 투어 중에는 이동 입력·이동체 틱을 시작하지 않는다.

### 횡단보도 자동 안전 연출

- 초록불에 횡단보도 첫 칸으로 이동하면: 0.6초 자동 멈춤 → 눈동자가
  좌→우로 움직임 → "멈춰요, 왼쪽 오른쪽을 봐요" 음성 → 손 든 자세로 전환.
- 횡단보도 위에 있는 동안 손 든 자세를 유지하고, 벗어나면 원래대로.
- 연출 중 입력은 큐에 넣지 않고 무시한다(0.6초뿐이므로 혼란 없음).
- 빨간불 진입 시도 시 기존 차단+안내("빨간불이에요, 기다려요")는 유지한다.

## 상태와 구성 요소

### `src/safety-route-layout.mjs`

- 건물 풋프린트 목록(id, 구역, x/y/w/h, 문 방향, 간판 텍스트) 추가
- 소품(나무·꽃밭·벤치) 좌표 목록 추가
- 친구 후보 칸을 건물 문 앞 칸으로 재정의
- 라이더 순찰 구간을 금지 칸(친구·문·횡단보도)과 겹치지 않게 재정의
- 골인 칸을 학교 정문 앞으로 조정(우측 끝 → 학교 문 앞)
- 신호등 마커 위치(횡단보도 진입부 양끝)를 데이터로 노출

### `src/safety-route-model.mjs`

- 이동 규칙 변경 없음
- 횡단 연출 상태(`crossingCeremony`: idle/stopping/looking/crossing) 추가
- 카메라 투어 상태(`tourActive`) 추가 — 활성 중 이동 무시

### `src/safety-route-scene.mjs`

- 건물·소품·학교 랜드마크·도착 매트 렌더링
- 신형 오브젝트(신호등 쌍, 3/4 자동차, SVG 라이더, 포크레인 공사장,
  열린 맨홀) 렌더링 — 기존 4개 보도 신호등 DOM 제거
- 미니맵 렌더링과 갱신
- 횡단 연출 자세(손 들기·눈동자)와 도착 폭죽 연출
- 가장자리 화살표에 학교 아이콘 병기

### `src/safety-route-camera.mjs`

- 투어 팬 경로(집→학교) 보간 지원, 키 입력 시 중단

### `src/app.mjs`

- 투어 시작·생략 연결, 횡단 연출 음성 트리거, 도착 축하 음성 연결

### `styles.css`

- 신규 오브젝트·건물·미니맵·연출 스타일 전면 교체(safety 구간)

## 오류 처리

- 랜덤 배치 실패 시 고정 안전 배치 사용(기존 유지). 고정 배치도 새 골인
  칸·순찰 구간 기준으로 갱신한다.
- 투어 팬 계산이 불가능하면 투어를 생략하고 바로 시작한다.
- SVG·장식 렌더링이 실패해도 충돌 판정과 텍스트 안내는 유지한다.
- 음성 재생 실패 시 연출(멈춤·살피기)은 그대로 진행한다.

## 테스트

### 유지 (수정 없음)

- 모델 규칙: 순서 수집, 횡단 조건, 이동체 정지·반전, 경로 검증, 난이도별
  요소 수 — `safety-route-model.test.mjs` 골격 유지

### 갱신

- 레이아웃: 건물 풋프린트가 잔디 안에만 있고 보행길·후보 칸과 겹치지
  않는지, 친구 후보가 문 앞 칸인지, 순찰 구간 금지 칸 규칙, 새 골인 칸
- 씬: 건물·학교·미니맵·신호등 쌍·신규 오브젝트 DOM 계약, 기존 신호등
  4개 제거 확인, 접근성 이름
- 연출: 횡단 연출 상태 전이(진입→멈춤→살핌→손들기→해제), 투어 시작·
  키 생략, 도착 연출 트리거
- 스타일: 새 CSS 변수·클래스 계약
- 브라우저 회귀: 1280×720 / 390×844 / 640×360에서 건물·미니맵·연출 확인
