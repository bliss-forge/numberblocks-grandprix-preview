# SRT 생동형 주행 애니메이션 설계

## 목표

기존 실사 SRT 열차와 운전실 이미지는 유지하되, 정지 사진을 조금 이동시키는 현재 장면을 속도와 주행 거리에 반응하는 실제 주행 장면으로 교체한다. 운전실에서는 하늘이 아니라 선로를 따라 달리는 시야가 보여야 하며, 외부 화면에서는 풍경의 깊이별 이동과 열차의 미세 움직임이 보여야 한다. 역 정차 중에는 열차 차체의 문짝이 실제로 열리고 닫혀야 한다.

## 확정 방향

동영상 배경이나 WebGL을 추가하지 않는다. 기존 사진을 원경 플레이트로 사용하고, 중경·근경·선로·전차선·차체 동작을 DOM/CSS 다층 패럴랙스로 구성한다. 모든 위치는 게임 모델의 `x`, `v`, `phase`, `doors`, `markerDistance`에서 결정하므로 일시정지, 감속, 부스터, 역 진입과 정확히 동기화된다.

## 장면 구조

### 운전실

- 운전실 사진은 고정 프레임으로 유지한다.
- 전면창 안쪽에 `하늘/원경`, `지면`, `자갈`, `침목`, `좌우 레일`, `전차선 기둥` 레이어를 둔다.
- 지평선은 창 높이의 약 38%에 두고 선로가 창 아래쪽까지 차지하도록 한다. 하늘만 보이는 구도를 금지한다.
- 침목과 전차선 기둥은 소실점에서 생성되어 화면 가장자리로 커지며 지나간다. 속도가 0이면 모든 위상이 고정된다.
- 터널과 역 플랫폼은 기존 상태 전환을 유지하되 같은 전면창 좌표계를 사용한다.

### 외부 화면

- 실사 사진은 원경으로 사용하며 구간마다 충분한 오버스캔 폭을 이동한 뒤 다음 사진으로 교차한다.
- 산·하늘은 느린 원경, 논밭·건물은 중간 속도, 울타리·전신주·선로는 빠른 근경으로 분리한다.
- 동일한 시간 동안 `원경 < 중경 < 근경 < 선로` 순으로 이동량이 커야 한다.
- 열차는 화면 중심에 유지하되 속도에 따른 차체 진동, 하부 그림자 흐름, 바퀴 회전 인상을 추가한다. 정차하면 모두 멈춘다.
- 사진 교차 시 오른쪽으로 되감기거나 빈 가장자리가 노출되지 않는다.

### 문 애니메이션

- 실사 열차 위에 SRT 색상과 창 형태를 맞춘 문 모듈을 정렬한다.
- `doors="closed"`에서는 좌우 문짝이 중앙에서 맞닿고, `doors="open"`에서는 양쪽으로 미끄러져 열린 내부 공간이 보인다.
- 문은 역 접근 중에는 닫혀 있고 `boarding/stopped` 상태에서만 열릴 수 있다. 출발 전 닫힘 상태로 복귀한다.
- 운전실의 기존 문 표시등은 상태 안내로 남기되, 이것을 실제 문 애니메이션으로 간주하지 않는다.

## 성능과 접근성

- 새 비디오, 3D 라이브러리, 네트워크 요청을 추가하지 않는다.
- 큰 래스터 이미지는 기존처럼 최대 두 장만 동시에 페인트한다.
- 움직임은 `transform`, `background-position`, `opacity` 중심으로 구현한다.
- `prefers-reduced-motion: reduce`에서는 강한 진동과 속도선을 제거하되 상태 변화와 문 열림/닫힘 결과는 유지한다.
- 가로형 모바일에서는 블러를 제거하고 레이어 수는 유지해 장면 의미가 사라지지 않게 한다.

## 검증 기준

- 240km/h에서 1초 사이 원경·중경·근경·선로의 실제 브라우저 좌표 또는 CSS 변수가 모두 변한다.
- 같은 시간 동안 이동량이 원경보다 근경에서 명확히 크다.
- 운전실 전면창 하단 영역에 지면·레일·침목이 실제로 렌더링된다.
- 정차 상태에서는 연속된 업데이트에도 모든 이동 위상이 변하지 않는다.
- 문을 열면 좌우 문짝의 실제 브라우저 변환 행렬이 서로 반대 방향으로 변하고, 닫으면 원위치한다.
- 기존 KTX SVG 모드와 1~5번 게임에는 변화가 없다.
