# 숫자블록 난이도·곱셈 캐릭터 확장 설계

작성일: 2026-07-20  
상태: 구현 및 검증 완료

## 1. 목표

- 홈 화면에서 세 게임에 공통으로 적용되는 난이도를 선택할 수 있게 한다.
- 3~5세가 한 번에 너무 많은 개체를 세지 않도록 숫자 세기의 범위를 제한하고 묶음 힌트를 제공한다.
- 곱셈 정답을 맞힌 뒤 결과에 맞는 캐릭터 또는 전용 곱셈 도우미가 등장하게 한다.
- 기존 숫자키 조작, 자연스러운 한국어·영어 음성, 별 점수와 게임 흐름을 유지한다.

## 2. 선택한 UX

검토한 방식은 홈 화면 상시 선택, 게임 시작 전 선택창, 게임 내부 설정의 세 가지다.

**홈 화면 상시 선택**을 채택한다.

- 게임을 시작하기 전에 현재 난이도를 바로 확인할 수 있다.
- 별도의 팝업이나 설정 화면이 없어 어린이의 클릭 수가 늘지 않는다.
- 마우스 클릭과 키보드 조작을 모두 지원한다.
- 마지막 선택은 브라우저에 저장하고 다음 접속 때 복원한다.
- 저장값이 없거나 잘못된 경우 기본값은 `차근차근`이다.

난이도는 `쉬움`, `차근차근`, `도전` 세 버튼으로 표시한다. 선택된 버튼은 색, 체크 표시, `aria-pressed` 상태로 구분한다. 홈 화면의 게임 선택 숫자키 `1`, `2`, `3`은 그대로 유지하며 난이도에는 별도의 키보드 단축키와 방향키 탐색을 제공한다.

## 3. 난이도 규칙

범위는 문제의 **정답**을 기준으로 한다. 더하기는 양의 정수 두 개, 곱셈은 1단부터 10단까지의 두 수를 사용한다.

| 난이도 | 숫자 세기 | 더하기 | 곱셈 |
|---|---:|---:|---:|
| 쉬움 | 1~10 | 합 2~10 | 1~10단 조합 중 결과 1~10 |
| 차근차근 | 1~20 | 합 2~50 | 1~10단 조합 중 결과 1~50 |
| 도전 | 제공하지 않음 | 합 2~100 | 1~10단 전체, 결과 1~100 |

추가 규칙:

- 곱셈의 두 수는 각각 1~10으로 제한한다.
- 같은 교환식만 지나치게 반복되지 않도록 최근 문제를 짧게 기억해 후보를 고른다.
- 더하기는 한쪽 수가 계속 1에 치우치지 않도록 범위 안에서 다양한 조합을 고른다.
- 난이도 선택이 명시적이므로 기존 연속 정답 기반 범위 상승은 제거한다. 연속 정답과 별 점수는 피드백용으로만 유지한다.
- `도전`을 선택하면 숫자 세기 카드를 비활성화하고 “도전에서는 더하기와 곱하기를 해요”라고 안내한다. 숫자키 `1`로 시작하려 해도 같은 안내만 표시한다.

## 4. 숫자 세기와 힌트

50개나 100개를 하나씩 세는 문제는 만들지 않는다.

### 쉬움

- 1~10개를 개별 블록으로 보여 준다.
- 1~10 숫자 캐릭터의 개성을 유지하되 실제로 셀 수 있는 블록 구성이 보이게 한다.

### 차근차근

- 1~20개를 5개 또는 10개 단위로 정렬한다.
- 10개가 넘는 경우 십 묶음과 낱개 사이에 시각적 간격을 둔다.
- 처음에는 정답 숫자를 쓰지 않고 개체만 보여 준다.

### 단계적 힌트

1. 일정 시간 입력이 없으면 5개 또는 10개 묶음의 테두리를 강조한다.
2. 오답이 누적되면 “10개 묶음 1개와 낱개 7개”처럼 수량 구조를 읽어 준다.
3. 마지막 힌트에서도 정답 숫자를 직접 대신 입력하지는 않는다.

힌트는 색만으로 구분하지 않고 테두리, 간격, 짧은 자막을 함께 사용한다.

## 5. 큰 수의 화면 표현

기존 캐릭터 이미지는 1~10만 있으므로 11 이상을 기존 이미지 한 장처럼 취급하지 않는다.

- 숫자 세기 11~20: 10개 묶음과 1~10개의 낱개 블록으로 구성한다.
- 더하기에서 11 이상인 피연산자: 숫자 카드와 십 묶음 막대·낱개 블록을 함께 사용한다.
- 곱셈: 최대 10×10 배열을 사용하며, 행과 열을 번갈아 옅게 구분해 100칸도 구조가 읽히게 한다.
- 작은 화면에서는 블록 셀 크기를 줄이되 수식과 답 입력 영역의 최소 크기는 유지한다.

## 6. 정답 캐릭터와 곱셈 도우미

캐릭터는 문제를 푸는 동안 정답을 노출하지 않고 **정답을 맞힌 뒤에만** 등장한다.

### 곱셈 결과 1~9

- 해당 숫자의 기존 캐릭터가 축하 애니메이션으로 등장한다.
- 예: `2×3`을 맞히면 6 캐릭터가 등장한다.

### 곱셈 결과 10~100

- 전용 곱셈 도우미가 정답 숫자 팻말을 들고 등장한다.
- 사용자 요청의 “10 이상”은 10을 포함하는 것으로 적용한다.
- 도우미는 보라색 계열의 둥근 블록형 몸체, 큰 눈, 밝은 표정, 가슴의 `×` 문양을 가진 독창적인 2D 애니메이션 캐릭터로 만든다.
- 기존 1~10 캐릭터와 색감·평면 질감·눈과 입의 비율은 맞추되 특정 원작 캐릭터를 그대로 복제하지 않는다.
- 팻말에는 큰 숫자와 완성된 수식을 함께 표시한다. 예: `6 × 8 = 48`.
- 등장 시 짧게 튀어 오르고 팻말을 들어 올린 뒤 멈춘다. 상시 흔들림은 사용하지 않는다.
- `prefers-reduced-motion`에서는 이동 없이 페이드인만 사용한다.

더하기 결과가 1~10이면 기존처럼 결과 캐릭터를 보여 주고, 11~100이면 완성된 수식과 십 묶음·낱개 결과 보드를 보여 준다. 곱셈 전용 도우미는 곱셈 게임에서만 사용한다.

## 7. 상태와 데이터 흐름

상태에 `difficulty`를 추가한다.

1. 홈 진입 시 저장된 난이도를 읽어 버튼과 게임 카드 상태를 동기화한다.
2. 난이도 버튼을 누르면 상태와 저장값을 갱신한다.
3. 게임 시작 시 모드와 난이도를 문제 생성기에 전달한다.
4. 문제 생성기는 난이도별 정답 범위와 곱셈 후보 규칙을 적용한다.
5. 숫자 세기에서는 일정 시간 뒤 묶음 힌트를 예약한다.
6. 정답 처리 시 모드와 결과에 따라 숫자 캐릭터, 큰 수 결과 보드, 곱셈 도우미 중 하나를 렌더링한다.
7. 홈 이동이나 새 문제 시작 시 힌트와 축하 타이머를 모두 취소한다.

## 8. 오류와 경계 조건

- 저장소 접근 실패: `차근차근`으로 계속하고 게임을 중단하지 않는다.
- 존재하지 않는 난이도: `차근차근`으로 정규화한다.
- 도전에서 숫자 세기 시작 시도: 화면 안내만 표시하고 게임 상태를 바꾸지 않는다.
- 10 이상의 결과를 기존 숫자 캐릭터 경로로 조회하지 않는다.
- 곱셈 도우미 이미지가 로드되지 않으면 수식과 정답 숫자 보드는 그대로 표시한다.
- 100은 세 자리 입력이므로 기존 접두 입력 로직을 유지하고 `1` 또는 `10` 입력 단계에서 오답 처리하지 않는다.
- 음성 답 파일이 10까지만 있는 경우 11~100은 숫자 파일 조합 또는 화면 자막으로 안전하게 폴백하며 게임 진행을 막지 않는다.

## 9. 검증

자동 테스트:

- 세 난이도의 모드별 정답이 범위를 벗어나지 않는다.
- 모든 곱셈 피연산자는 1~10이고, 도전에서는 10×10까지 생성할 수 있다.
- 쉬움·차근차근 숫자 세기의 최대값은 각각 10과 20이다.
- 도전에서는 숫자 세기 시작이 차단된다.
- 난이도 저장·복원과 잘못된 저장값 폴백이 동작한다.
- 1~9 곱셈 정답은 해당 캐릭터, 10~100은 도우미 결과를 선택한다.
- 세 자리 정답 `100`의 접두 입력이 정상 동작한다.
- 기존 키보드, 음소거, 홈 이동, 오디오 취소 테스트가 계속 통과한다.

브라우저 검증:

- 난이도 버튼과 세 게임 카드가 마우스로 클릭된다.
- 키보드만으로 난이도 선택과 게임 시작이 가능하다.
- 1280×720과 1440×900에서 20개 세기, 50 이하 더하기, 10×10 곱셈이 겹치지 않는다.
- 숫자 세기 묶음 힌트가 정답을 즉시 노출하지 않는다.
- `2×3` 정답 후 6 캐릭터가 등장한다.
- 결과 10 이상 정답 후 곱셈 도우미와 완성 수식이 등장한다.
- 모션 감소 환경에서도 정보가 손실되지 않는다.
- 콘솔 오류와 누락된 이미지 요청이 없다.

## 10. 완료 기준

- 홈에서 공통 난이도를 선택하고 다음 접속에도 유지할 수 있다.
- 확정된 범위대로 세기·더하기·곱셈 문제가 생성된다.
- 숫자 세기는 최대 20까지만 제공되고 묶음 힌트가 동작한다.
- 구구단은 1단부터 10단까지 지원한다.
- 곱셈 정답 1~9에는 기존 숫자 캐릭터, 10 이상에는 전용 도우미가 등장한다.
- 자동 테스트와 실제 브라우저 검증을 모두 통과한다.

## 11. 구현 결과

- 공통 난이도 선택과 브라우저 저장을 적용했다.
- 숫자 세기 묶음 힌트와 큰 수 화면 표현을 적용했다.
- 도전 난이도에서 숫자 세기를 비활성화하고 안내 문구를 제공한다.
- 곱셈 정답 1~9에는 기존 숫자 캐릭터, 10~100에는 전용 곱셈 도우미와 완성 수식을 적용했다.
- 1~100 한국어·영어 정답 음성을 오프라인 자산으로 적용했다.
- 자동 테스트 51개를 통과했다.
- 1280×720 브라우저에서 난이도 클릭·저장·숫자키·방향키·12개 묶음 힌트·90+7·2×3·10×10·100 입력·정답 캐릭터를 검증했다.
- 브라우저 콘솔 오류와 누락 자산 요청은 0건이다.
