# 알록달록 물감 놀이 — 설계 (8번 게임)

2026-08-05 · 3안 설계 패널 심사(v1: 기차 색칠 공장 채택) → 목업 검토에서 사용자 피벗:
"기차 말고 자동차, 아니면 물감놀이" → 시안 D(자동차 가게)·E(물감 아뜰리에) 목업 비교 →
**D+E 조합 확정: 아뜰리에(E) 베이스 + 칠할 대상에 자동차·탈것 그림을 자주 등장**.

## 컨셉

무지개 몸 **일곱이(seven.png)의 그림 공방**. 이젤 위에 회색 윤곽 그림(당근·개구리·자동차…)과
목표 색 견본이 걸리면, 아이는 물감 튜브 두 개를 골라 유리병에 짜 넣는다 — 두 색이 층으로
쌓였다가 **⎵로 저으면 소용돌이치며 새 색으로 변신**(이 순간이 핵심 스펙터클). "칠하기!"를
누르면 병이 기울어 그림이 그 색으로 차오른다. 완성 그림은 **벽 액자 갤러리**에 걸린다.

- **물감 튜브 마스코트** — 몸색=물감색: 1(하나)=빨강 · 3(셋)=노랑 · 5(다섯)=파랑 ·
  9(아홉)=검정 · 10(열)=하양. 숫자키↔색 연결이 자연 학습.
- **그림 주제 로테이션** — 과일/자연(당근·포도·벚꽃), 동물(개구리·병아리), **탈것(자동차·
  버스·헬리콥터·배 — 출제 가중치 높음)**. 회색 윤곽 + 견본 색이 힌트 그림 역할.
- **무지개 피날레** — 갤러리에 7색 그림이 모이면 일곱이가 무지개를 그려 주는 대단원.

## 학습 4단계 (난이도 매핑: 쉬움=1~2 · 차근차근=2~3 · 도전=3~4)

1. **색 이름 배우기** — 혼합 없음. 견본+음성 듣고 튜브 하나 골라 바로 칠하기.
2. **두 색 섞기** — 재료 힌트 물방울 2개 표시. 빨+노=주황 · 노+파=초록 · 빨+파=보라.
3. **연하게 · 진하게** — 하양/검정 튜브 등장. 분홍·하늘색·밤색·남색.
4. **거꾸로 색깔 박사** — 힌트 제거, 목표 색에서 재료 역추론. 2회 못 맞히면 힌트 복귀.

## 코어 루프

제시(일곱이 부탁 + 회색 그림 + 견본 + 음성) → 튜브 2개 짜기(병에 층으로 쌓임, 2색 차면 잠김)
→ **⎵ 젓기**(연타 3회 목표, 1회만 눌러도 느리게 완성되는 관용 — 소근육 배려) →
칠하기!(병 기울어 그림 채색) → 결과: 일치=일곱이 환호·별+1·갤러리 액자 / 불일치=결과 색
실명 호명("보라가 됐네! 보라는 포도 색이야") → 헹구기(물이 차올라 병 세척) → 재도전.
벌점·버저·빨간 X 없음. 힌트 에스컬레이션: 2회차 물방울, 3회차 정답 튜브 반짝(주기 ≥0.8s).
[배수/헹구기 버튼]으로 언제든 무판정 리셋.

## 조작 (불변 원칙 준수)

- ←/→: 하단 [튜브들 → 헹구기 → 칠하기!] 포커스 순환 · Space/Enter: 실행(병에 2색이 차면 Space=젓기)
- 숫자키 1·3·5·9·0: 해당 튜브 즉시 짜기(0=열=하양)
- 터치/마우스: 탭 1회(병 탭=젓기), 전 타깃 ≥44px. Esc=처음으로. 시간 압박 없음.

## 혼합 테이블 (MIX_TABLE — 단일 진실, frozen)

런타임 RGB 보간 금지(노+파=회색 함정). 순서 무관 키 룩업, 결과 헥스는 수작업 튜닝:

| 조합 | 결과 | 단계 | 예시 그림 |
|---|---|---|---|
| 빨+노 | 주황 | 2 | 당근, 주황 자동차 |
| 노+파 | 초록 | 2 | 개구리, 초록 버스 |
| 빨+파 | 보라 | 2 | 포도, 보라 헬리콥터 |
| 빨+하양 | 분홍 | 3 | 벚꽃, 분홍 자동차 |
| 파+하양 | 하늘색 | 3 | 풍선, 하늘색 배 |
| 빨+검정 | 밤색 | 3 | 곰, 밤색 트럭 |
| 파+검정 | 남색 | 3 | 밤하늘, 남색 기차? (탈것 로테이션) |

1단계 단일색: 빨강(사과·소방차)·노랑(병아리·택시)·파랑(파랑새·버스).
