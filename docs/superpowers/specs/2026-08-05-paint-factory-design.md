## 컨셉

아이는 차량기지 색칠 공장의 도색 기사. 넘버블록 손님이 목표 색 주문서를 들고 오면
회백색 초벌 열차(Canonical `trainSideSvg` 재사용)가 입고된다. 물감 통 두 개를 골라
믹싱 탱크에 붓고 — 두 색이 소용돌이치며 혼합색으로 변신 — "도색!"으로 스프레이 터널을
통과시키면 열차가 그 색 리버리로 칠해진다. 완성 열차는 기적을 울리며 출발해 화면 상단
**차고 컬렉션**에 그 색 미니 열차로 쌓인다.

이식 장치:
- **물감 통 마스코트** — 통마다 넘버블록이 서 있고 몸색=물감색: 1(하나)=빨강, 3(셋)=노랑,
  5(다섯)=파랑, 9(아홉)=검정(진하게), 10(열)=하양(연하게). 숫자키↔색 연결이 자연 학습된다.
- **색 주인 손님 캐스팅** — 주문 색과 몸색이 같은 넘버블록이 손님으로 온다
  (주황 주문=둘, 초록=넷, 분홍=여덟). 완성 시 "내 색깔이랑 똑같네!" 축하.
- **무지개 피날레** — 차고에 7색이 모이면 무지개 몸 일곱이가 등장하는 대단원.

## 학습 5단계 (난이도 = 기존 difficulty 3종에 매핑)

1. **색 이름 기차** — 혼합 없음. 견본+음성 듣고 통 하나 골라 바로 도색. 기본색 이름 학습.
2. **두 색 섞기** — 주문서에 재료 힌트 물방울 2개. 빨+노=주황 · 노+파=초록 · 빨+파=보라.
3. **진짜 도색 기사** — 힌트 제거, 역추론. 2회 못 맞히면 힌트 물방울 복귀(좌절 방지).
4. **연하게 · 진하게** — 하양/검정 통 등장. 분홍(빨+하양)·하늘색(파+하양)·밤색(빨+검정)·남색(파+검정).
5. **특급 주문 편성** — 3량 칸마다 다른 주문, 완성 편성 퍼레이드 출발.

난이도 매핑: 쉬움=1~2단계 · 차근차근=2~3단계 · 도전=3~5단계.

## 코어 루프

제시(손님+주문서+음성) → 붓기(통 선택, 즉시 탱크 반영 — 2색 차면 잠김) →
혼합 변신(1.2s 보간+소용돌이) → [배수 마개로 언제든 무판정 리셋] → 도색! (스프레이 터널,
좌→우 리버리 채색) → 결과: 일치=환호·기적·별+1·차고 적재 / 불일치=결과 색 실명 호명
("보라색 기차가 됐네! 그런데 주문은 주황색이야") → 세척 터널 물보라 → 재도전.
벌점·버저·빨간 X 없음. 힌트 에스컬레이션: 2회차 물방울, 3회차 정답 통 반짝(주기 ≥0.8s).

## 조작 (불변 원칙 준수)

- ←/→: 하단 한 줄 [물감 통들 → 배수 마개 → 도색!] 포커스 순환 · Space/Enter: 실행
- 숫자키 1·3·5·9·0: 해당 통 즉시 붓기(0=열=하양)
- 터치/마우스: 탭 1회, 전 타깃 ≥44px. Esc=처음으로. 시간 압박 없음.

## 혼합 테이블 (MIX_TABLE — 단일 진실, frozen)

런타임 색 보간 금지(RGB lerp는 노+파=회색 함정). 순서 무관 키의 수작업 룩업:

| 조합 | 결과 | 비고 |
|---|---|---|
| 빨+노 | 주황 | 2단계 |
| 노+파 | 초록 | 2단계 |
| 빨+파 | 보라 | 2단계 |
| 빨+하양 | 분홍 | 4단계 |
| 파+하양 | 하늘색 | 4단계 |
| 빨+검정 | 밤색 | 4단계 |
| 파+검정 | 남색 | 4단계 |

단일색 도색(1단계): 빨강·노랑·파랑 그대로. 헥스 값은 구현 시 캐릭터 고유색
(character-designs 상수)과 열차 리버리 톤에 맞춰 튜닝하되 테이블에만 존재한다.

## 리스크 (심사에서 인정된 것)

- 세척 연출이 정답 보상보다 재미있어지는 역전 — 세척은 짧고 담백하게, 축하는 크게.
- 목표색 풀(~10종) 소진 — 5단계 편성 조합과 차고 컬렉션으로 반복 유인 보완, 자유 도색 모드는 백로그.
- 화면(가산 발광)과 실제 물감(감산)의 미묘한 차이 — 테이블 튜닝으로 교육적 대표색을 직접 지정.
