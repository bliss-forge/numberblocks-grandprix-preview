## 4. 한 판의 흐름

```
출동(오디오 언락 = 첫 Space) → [체크포인트 있으면 이어서/처음부터 2택]
  ↓
loading 짐 싣기 (Space 1회 = 상자 1개 + 세기) → depart-wait
  ↓
driving 주행 1 (30~40초) → parking 주차 존 → [correcting 지나침 보정]
  ↓
101동: label 클로즈업 → walk 로비 → elevator-select → (ride) → walk 복도
       → doorstep 초인종 → handover 건네주기 → 서프라이즈 개봉
       → 2건째(리추얼 단축) → descend-first(첫 하행만 조작)
  ↓
driving 주행 2 → parking
  ↓
102동: 큐 과제(라벨 2장·버튼 2개, 작은 수 먼저 = 보너스 별) → 배달 2건
  ↓
finale 피날레 배달(풀 3종: 생일 / 이사 환영 / 깜짝 답례)
  ↓
정산(별·오늘 만난 친구·처음 만난 배지)
```

부재 배달(시드 0~1회, 피날레 제외)은 `doorstep`에서 분기: 딩동 1회 → 즉시 불 꺼짐 → `absent-choice` 2택(문 앞 찰칵 / 경비실) → 어느 쪽이든 성공.

**타임박스 목표** — 출동+싣기 40s · 주행1+주차 50s · 101동 2건+첫 하행 100s · 주행2+주차 50s · 102동 큐 2건 70s · 피날레 60s · 정산 20s = **≈390s(6.5분)**. 배달 1건 ≤55초, 판당 의무 세기 비트 ≤8.

## 5. 유휴 감시 (진행 기준 시계)

시계는 **"목표 진행이 없는 시간"**(입력 유무 무관). 6초 → 힌트, 12초 → 자동 어시스트. 주도권 반환은 **목표 키 입력에만**.

| phase | 6초 | 12초 (자동 phase) |
| --- | --- | --- |
| loading | Space 아이콘 + "눌러서 실어 볼까?" | `autoload` 0.8초 간격 자동 적재 |
| depart-wait | ↑ 아이콘 + "부릉부릉, 가볼까?" | `autocreep` |
| driving | ↑ 아이콘 | `autocreep` |
| parking | 손바닥 아이콘 점멸 | `autopark` + "같이 주차했어요!" |
| walk | 진행 방향 화살표 + 문패 반짝 | `autowalk` |
| elevator-select | 라벨→버튼 날아가기 + "숫자 ○를 눌러 봐!" | `autoride` + "같이 눌렀어요!" |
| descend-first | 1 버튼 점멸 | `autoride` |
| doorstep | 초인종 아이콘 + "딩동 눌러 볼까?" | `autobell` |
| handover | Space 아이콘 | `autohand` |
| absent-choice | 양쪽 아이콘 교대 점멸 | `autochoice`(문 앞 찰칵) |
| finale-candle | Space 아이콘 | `autoblow` |

자동 진행 phase(label 클로즈업 · ride 중 · 연결부 · correcting · auto*)는 정의상 무진행이 없다.
**테스트로 고정**: "phase 집합 = 이 표의 행 집합".

## 8. 서프라이즈 6종

수취인 번호 N만큼 튀어나온다. 시각 스폰 ≤8(초과는 덩어리 1노드 + 마지막 수 명명), 세기 강제는 N ≤ 6에서만, 판당 최대 3회.

| 내용물 | 연출 | reduced-motion |
| --- | --- | --- |
| 풍선 | 위로 둥실 + 좌우 흔들 | 진폭 1/4, 정지 배치 |
| 사과 | 포물선 튀어나옴 + 통통 | 즉시 배치, 통통 제거 |
| 아기 오리 | 줄지어 아장아장 | 이동 유지(속도 1/2), 뒤뚱임 제거 |
| 야광별 | 반짝 점멸(≤3Hz) | 정적 발광 |
| 장난감 기차 | 바닥을 한 바퀴 주행 | 정지 배치 |
| 반딧불이 병 | 병 속 점멸 + 부유 | 정적 발광, 부유 제거 |
