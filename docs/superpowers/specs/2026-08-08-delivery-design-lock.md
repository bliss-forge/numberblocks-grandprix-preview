## 5. STEP별 화면 레이아웃

공통 뼈대: `[헤더] / [좌 정보 · 중앙 무대 · 우 조작] / [하단 마스코트 안내]`

### STEP 1 — 단지 운전
- **좌**: `목표` → `702호` · `배송한 택배` → 📦 `0 / 5`
- **중앙**: 단지 지도. 집 4채 **601 · 503 · 702 · 401**, 목표 집만 초록 링 + 별 + “여기가 702호!” 말풍선.
  도로 격자·중앙 점선·횡단보도·보도, 연못, 벤치, 나무, 꽃, 라바콘, 신호등, 위치 마커(초록 핀), 택배차.
- **우**: `이동 명령` 슬롯 4칸(아래 번호 `1 2 3 4`) / `방향 버튼` / `▶ 출발!`(초록)
- 방향 버튼: **↑ ← → ↓ 네 방향**
  (레이아웃 가이드 패널에는 ⬆⬅➡ 3개가, §6 버튼 스타일 시트에는 ⬇ 가 따로 그려져 있어 합쳐 4방향으로 확정)

### STEP 2 — 엘리베이터
- **좌**: 샤프트 단면. 층 번호 기둥 **7·6·5·4·3·2·1**, 칸 위치, 세로 점열 위치 표시기(목표 층에 초록 점)
- **중앙**: 엘리베이터 안 (금속 벽 · 천장 조명 2개 · 손잡이 · 원근 바닥)
- **우**: `목표 층` → `7층` · `누른 버튼` 3×3 = `7 8 9 / 4 5 6 / 1 2 3` (누른 버튼만 초록) + `🔔`

### STEP 3 — 문 앞 전달 (호수 찾기)
- **중앙**: 복도. 나무문 3개 **701 · 702 · 703**, 목표 문만 금빛 링 + 별 + 문 위 조명.
  택배 기사(넘버블록)가 상자를 들고 서 있다.
- **우**: `내가 찾는 호수` → `702호` · `힌트 라벨` → `702호` `702호` (2장)

### STEP 4 — 문 앞 전달 (전달 순간)
- **무대 좌상단 카드**: `받는 친구` → `702호`
- **중앙**: 열린 702호 문, 받는 친구(빨강 넘버블록)가 손 흔들며 말풍선
  “나는 과일 상자를 기다리고 있었어!”. 컨베이어 위 상자 3종 **과일 상자 · 화장품 상자 · 장난감 상자**,
  고른 상자만 금빛 링 + 발광 + 살짝 들림. 아래 `←` `🔔` `→`
- **우**: `조작 방법` → `← →` 선택 / `Space` 전달 · `전달한 수` → `0 / 5` + 🚚 + 점 4개

## 9. 폰트

| 용도 | 지정 |
| --- | --- |
| 숫자 / 제목 | **Pretendard ExtraBold** (`font-weight: 800`) |
| 본문 | **Pretendard Bold** (`font-weight: 700`) |

저장소는 웹폰트 파일을 쓰지 않고 시스템 폰트 스택만 쓴다(무의존·무빌드 원칙).
따라서 **`Pretendard` 를 스택 맨 앞에 두고 기존 스택을 폴백**으로 남긴다. 폰트 파일은 추가하지 않는다.

## 11. 불변 조건 (기존 계약)

- 키: 숫자 `0~9` · 화살표 · `Space` · `Esc`(홈). **새 키 0개.**

- 터치 타깃 ≥ 44×44px, `prefers-reduced-motion` 전면 대응.
- 1280×720 · 390×844 가로 스크롤 0.
- 의존성 0 · 빌드 0 · 테스트는 `node --test` 만.
- 애니메이션은 `transform` / `opacity` 만.
- 새 이미지 자산 생성 금지 (인라인 SVG + 기존 캐릭터 PNG).

### 홈 화면 부수 수정
9번 카드로 홈이 한 줄 길어지자, 모바일에서 끝까지 스크롤했을 때 1번 카드가 좌상단
크레딧에 깔렸다. 여백으로는 못 푼다 — 카드 행 간격(197px)이 크레딧이 가리는 띠(208px)보다
좁아 어떤 스크롤 위치에서도 어느 한 행은 반드시 걸린다. 크레딧을 `#home` 안으로 옮겨
카드와 함께 스크롤되게 했다. 카드가 10장이 되어도 성립한다.
