# SRT 시간대·지형 실사 자산 설계

## 목표

기존 SRT 실사 자산의 카메라 구도와 픽셀 정렬을 유지하면서 야간, 새벽,
노을 및 지형별 변형을 추가한다. 새 장면을 다시 구성하지 않고 기존 장면을
재조명하는 것이 핵심이다. 최종 산출물은 Claude가 매니페스트와 스왑 로직에
연결할 수 있도록 지정된 경로와 파일명을 그대로 사용한다.

## 제작 방식

순수 재생성은 기하를 흔들 수 있고, 단순 색 보정은 조명 표현이 약하다.
따라서 ImageGen 편집 결과를 원본과 합성하는 하이브리드 재조명을 사용한다.

1. 기존 파일을 ImageGen 편집 대상 또는 필수 레퍼런스로 사용한다.
2. 생성 결과에서 시간대별 조명, 하늘색, 반사광만 취한다.
3. 원본의 구조적 고주파 정보와 알파 마스크를 다시 합성해 좌표를 고정한다.
4. 지정 해상도로 정규화하고 WebP는 `cwebp -q 82`로 변환한다.
5. 자동 실측과 육안 비교를 모두 통과한 파일만 저장소 자산으로 채택한다.

## 산출물

### 1순위: 야간 열차 스프라이트

- 경로: `assets/train-realistic/motion/srt-side-transparent-night.png`
- 크기: 2400×640, RGBA PNG
- 기준: `srt-side-transparent.png`
- 보존: 실루엣, 차량 수, 코, 보라색 띠, 바퀴와 접합부 위치, 투명 여백
- 변경: 어두운 차체, 따뜻한 객실등, 전조등, 짙어진 하부 그림자
- 검증:
  - 알파 마스크 외곽은 원본과 동일해야 한다.
  - 바퀴 최하단은 높이 61.7% 지점에서 1% 이내다.
  - 접합부 기준선 32%, 43.9%, 55.7%, 67.6%, 79.5%를 유지한다.

## 공통 시각 규칙

- 한국 고속철 풍경의 포토리얼 톤을 사용한다.
- 새 사람, 얼굴, 읽을 수 있는 텍스트, 새 로고, 워터마크를 넣지 않는다.
- 기존 이미지의 작은 표식은 재생성하거나 강조하지 않는다.
- 시간대 변화는 하늘, 환경광, 반사광, 인공조명에만 적용한다.
- 과도한 HDR, 영화적 안개, 판타지 색감, 비현실적 광원은 피한다.

## 후처리와 용량

- ImageGen 원본은 작업 트리의 임시 디렉터리에 보관하고 최종본만 자산
  디렉터리에 둔다.
- 배경은 `cwebp -q 82`로 변환하며 장당 100~350KB를 목표로 한다.
- 목표보다 큰 경우 해상도를 낮추지 않고 메타데이터 제거와 품질 80까지의
  미세 조정만 허용한다.
- 열차 PNG는 알파 손실을 막기 위해 무손실 또는 고품질 PNG 최적화만 한다.

## 검증과 실패 처리

각 파일에 대해 해상도, 색상 모드, 알파, 파일 크기, 구조 정렬을 검사한다.
ImageGen 결과가 원본 기하를 바꾸면 그대로 사용하지 않고 원본 구조를 더
강하게 합성한다. 두 차례 보정 후에도 1% 정렬 기준을 넘으면 해당 변형은
순수 원본 기반 색·조명 보정으로 대체한다. 산출물은 접촉 시트로 함께
검토하고, 기존 전체 테스트를 실행해 자산 예산 회귀가 없는지 확인한다.

## 범위

이번 브랜치는 이미지 10장과 제작·검증 기록만 추가한다. 매니페스트,
시간대 스왑 로직, 게임 코드 변경은 Claude의 후속 작업 범위다.
