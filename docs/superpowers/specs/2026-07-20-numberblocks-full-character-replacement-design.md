# 숫자블록 1~100 캐릭터 전면 교체 설계

작성일: 2026-07-20  
상태: 사용자 설계 승인 후 명세 검토 대기

## 1. 목표

- 현재 음성, 난이도, 문제 생성, 입력, 점수와 게임 진행 방식은 변경하지 않는다.
- 숫자 `1`부터 `100`까지 모든 정답에 독립된 캐릭터 이미지를 제공한다.
- `11` 이상에서 결과 보드나 공통 곱셈 도우미로 바뀌는 시각적 단절을 제거한다.
- 사용자가 제공한 1~100 참고표의 숫자별 블록 배열, 실루엣과 색상 흐름을 참고한다.
- 현재 1~10 PNG에서 좋은 반응을 얻은 큰 눈, 밝은 표정, 입체 명암과 투명 배경 품질을 유지한다.

## 2. 교체 범위

- 기존 1~10 캐릭터 PNG를 포함해 1~100 전체를 하나의 통일된 세트로 교체한다.
- 기존 `multiply-helper.png`는 정답 캐릭터로 더 이상 사용하지 않는다.
- 숫자 세기, 더하기, 곱셈 모두 정답을 맞힌 뒤 정답 숫자의 캐릭터를 표시한다.
- 문제를 푸는 동안에는 정답 캐릭터를 노출하지 않는다.
- 피연산자와 세기 문제의 수량 표현은 현재 방식을 유지한다. 이번 작업의 범위는 정답 캐릭터다.

## 3. 시각 언어

### 공통 품질

- 세로 기준 약 1500px의 고해상도 RGBA PNG로 저장한다.
- 배경은 완전 투명하게 처리한다.
- 블록은 둥근 모서리, 부드러운 그라데이션, 가장자리 하이라이트와 약한 자체 그림자를 사용한다.
- 눈은 흰자, 검은 동공과 작은 반사광을 갖는다.
- 입은 흰 치아와 혀가 보이는 밝은 애니메이션 표정으로 만든다.
- 팔과 다리는 몸체 색상 또는 강조색과 조화를 이루게 한다.
- 캐릭터 외부에 숫자, 이름, 수식, 워터마크를 넣지 않는다.

### 숫자 정확성

- 몸체의 블록 칸 수는 해당 숫자와 정확히 일치해야 한다.
- 합성수는 가능한 경우 대표적인 직사각형 배열을 사용한다.
  - `12`: 3×4
  - `20`: 4×5
  - `25`: 5×5
  - `36`: 6×6
  - `48`: 6×8
  - `100`: 10×10
- 소수와 직사각형으로 표현하기 어려운 수는 참고표처럼 기본 직사각형에 남는 블록을 윗줄, 옆줄 또는 계단으로 붙인다.
- 칸 구분선은 축소 화면에서도 읽히도록 유지한다.

### 색상 계열

- 1~10: 각 숫자의 기존 대표색을 유지하되 새 세트의 재질로 다시 제작한다.
- 11~19: 흰색 몸체와 빨간 윤곽을 중심으로 일의 자리 강조색을 사용한다.
- 20대: 주황·황토색
- 30대: 노랑·금색
- 40대: 초록
- 50대: 청록·하늘색
- 60대: 보라
- 70대: 보라를 바탕으로 무지개 또는 일의 자리 색 띠
- 80대: 분홍
- 90대: 회색·은색
- 100: 산호색·빨강

색상은 참고표의 흐름을 따르되 게임의 밝은 무대 배경에서 충분한 대비를 확보한다.

## 4. 캐릭터 개성

- 모든 캐릭터가 똑같은 얼굴 위치와 자세를 반복하지 않게 한다.
- 세로형은 얼굴을 중간 또는 아래쪽에, 정사각형은 중앙에 배치한다.
- 긴 소수 캐릭터, 정사각수 캐릭터, 10의 배수 캐릭터는 서로 다른 실루엣을 갖는다.
- 왕관, 안경, 나비넥타이, 별, 작은 색 띠 같은 장식은 참고표에서 해당 숫자의 구분에 도움이 될 때만 제한적으로 사용한다.
- 장식 때문에 블록 칸이 가려져 개수를 읽기 어려워지지 않게 한다.

## 5. 제작 방식

숫자 정확성과 이미지 품질을 함께 확보하기 위해 혼합 제작 방식을 사용한다.

1. 이미지 생성으로 현재 1~10의 질감과 참고표의 색상 흐름에 맞는 얼굴, 팔다리, 블록 재질의 기준 스타일을 만든다.
2. 숫자별 배열 데이터로 정확한 개수의 블록 몸체를 고해상도로 합성한다.
3. 숫자별 얼굴 위치, 자세, 강조색과 제한된 장식을 적용한다.
4. 투명 PNG로 렌더링하고 자동 검증한다.
5. 1~20을 먼저 게임에 연결해 화면 비율과 질감을 확인한 뒤 동일 파이프라인으로 21~100을 완성한다.

이 방식은 생성형 이미지에만 의존할 때 발생할 수 있는 블록 개수 오류를 막고, 단순 CSS 도형보다 입체적이고 일관된 결과를 제공한다.

## 6. 애플리케이션 연결

- 캐릭터 메타데이터를 1~100까지 확장한다.
- 정답 화면은 게임 종류와 관계없이 `answer`에 대응하는 캐릭터를 선택한다.
- 캐릭터는 필요한 순간에 불러와 초기 로딩 부담을 줄인다.
- 세로로 긴 캐릭터와 넓은 캐릭터에 맞춰 이미지의 최대 너비와 최대 높이를 자동 조정한다.
- 기존 정답 등장·축하 애니메이션과 모션 감소 설정을 그대로 사용한다.
- 이미지 로딩 실패 시 수식과 수량을 표시하는 기존 결과 보드로 대체하여 게임 진행을 막지 않는다.

## 7. 변경하지 않는 항목

- 한국어·영어 음성 파일과 재생 순서
- 효과음과 음성 덕킹
- 쉬움·차근차근·도전 난이도 범위
- 숫자 세기 묶음 힌트
- 더하기·곱셈 문제 생성 규칙
- 별 점수, 오답 처리와 다음 문제 전환 시간
- 마우스와 PC 키보드 조작

## 8. 검증

### 자동 검증

- 1~100에 대응하는 PNG 파일이 모두 존재한다.
- 모든 파일이 비어 있지 않고 RGBA 투명 채널을 가진다.
- 이미지 크기가 품질 기준을 충족한다.
- 캐릭터 메타데이터가 1~100을 빠짐없이 포함한다.
- 숫자 세기, 더하기, 곱셈의 정답 화면이 모두 정답 캐릭터를 선택한다.
- 존재하지 않거나 로딩에 실패한 이미지의 결과 보드 대체 경로가 유지된다.
- 기존 음성과 게임 모델 테스트가 변경 없이 통과한다.

### 시각 검증

- 1, 10, 11, 12, 17, 20, 25, 36, 48, 50, 64, 72, 81, 90, 99, 100을 대표 표본으로 확인한다.
- 세로형, 정사각형, 가로형, 계단형이 게임 무대와 겹치지 않는다.
- 1280×720 화면에서 눈·입과 블록 구분선이 식별된다.
- 참고표의 십 단위 색상 흐름과 숫자별 실루엣이 느껴진다.
- 콘솔 오류와 누락 이미지 요청이 없다.

## 9. 완료 기준

- 1~100 모든 숫자가 통일된 고해상도 캐릭터 PNG를 가진다.
- 11 이상에서도 공통 도우미나 단순 결과 보드 대신 정답 캐릭터가 등장한다.
- 모든 게임에서 정답 후 동일한 캐릭터 선택 규칙을 사용한다.
- 음성과 게임 방식은 기존 동작을 유지한다.
- 자동 테스트와 대표 표본 브라우저 검증을 통과한다.
