# 초안 — "칙칙폭폭 기관사" KTX/SRT 운전 미니게임 (사용자 제출 design-final)

> 사용자 요구 요약 (2026-08-02 제출 시점):
> - 직접 KTX/SRT를 운전해 목적지까지 가는 게임
> - 넘버블럭스 손님을 태우면서 감
> - 1인칭·3인칭 모두 볼 수 있게
> - 이동하면서 배경 전환 (바다, 산, 터널, 밤 등)
> - 4~7세가 엄청 재미있게, 많이 어렵지는 않지만 너무 단순하지도 않은 난이도
>
> 아래는 사용자가 제출한 설계 원문이다. 이 문서를 기준으로 M0 감사(같은 날짜 audit 문서)와
> LLM 협회 심의를 거쳐 최종판(design-v2)을 만든다.

---

## 0. 한 줄 컨셉

**"오늘은 네가 기관사야."** 아이가 SRT 기관사가 되어 수서에서 부산까지 달린다. 역마다 넘버블럭스 친구들이 기다리고, 스페이스 한 번에 한 명씩 태우며 함께 수를 센다. 속도계의 큰 숫자, 경적에 답하는 세상(오리·소·반대편 열차), 운전실과 바깥을 오가는 두 개의 눈. 시작할 때 기관사 모자를 쓰고 경례하며, 게임은 시종일관 아이를 "기관사님"이라 부른다.

## 1. 코어 루프와 노선

- v1 노선: SRT 1개 — 수서 → 동탄 → 대전 → 동대구 → 부산 (5역 4구간). 역은 그림 아이콘 구분(수서=출발 깃발, 동탄=아파트숲, 대전=과학 로켓, 동대구=사과, 부산=갈매기+바다). 역 이름은 항상 음성 병행.
- 두 번째 열차(KTX 파란 스킨)는 별 30개 해금 보상.
- 코어 루프 = 한 구간(약 70~100초), 한 판 5~7분:
  [출발 전 탑승](수서에서도 친구들이 탄다) → 문 닫기(Space, 차임 3회) → ↑ 홀드로 출발 → [주행] 이벤트 1~2개 + 경적 응답 놀이 + 속도 마일스톤 → 도미솔도 차임 + "잠시 후 도착!" → [접근·정차] 어시스트 봉투 + 딱 멈추기 버튼 + 오버런 자동 보정 → 별 1~3(항상 ≥1) → 문 열기 → [탑승] Space 1회 = 친구 1명 + 세기 음성 → 문 닫기 → 다음 구간.
- 종착 부산: 전원 하차 2단 세기 피날레(일반 친구 세기 후 큰 친구 "그리고... 백!" 분리) + "오늘 만난 친구" 요약 + 별 정산 + "고마워요, 기관사님!".
- 감정 곡선: 마지막 구간(동대구→부산)에 바다+갈매기 고정 이벤트를 v1로 승격, "끝이 제일 좋다".

## 2. 조작 매핑 (숫자키 + 방향키 + Space만)

| 키 | 주행 중 | 접근(정차 존) | 정차·탑승 중 |
|---|---|---|---|
| ↑ (hold) | 가속 | 가속(봉투 클램프) | 문 닫힘 상태면 출발 |
| ↓ (hold) | 브레이크 | 브레이크 | (무시+뿅) |
| Space | 경적 | 딱 멈추기(경적 비활성) | 문 열기 → 친구 1명 태우기 → (잠금 후) 문 닫기 |
| 1 / 3 | 운전실(1인칭) / 바깥(3인칭) 뷰 | 동일 | 동일 |
| 0 | 2초 홀드 = 홈으로(링 게이지, 놓으면 취소 → 그림 2택 확인) | 동일 | 동일 |
| 2, 4~9 | 무동작 + "뿅" | 동일 | 동일 |
| ←/→ | v1 무동작(+사운드) | 확인 2택에서만 | 동일 |

- 키 리핏 미사용: event.repeat 무시, keydown/keyup 눌림 상태를 고정 스텝 시뮬이 소비.
- 뷰 전환: repeat 무시 + 400ms 쿨다운 + 250ms 크로스페이드.
- phase 전환 직후 250ms 입력 스왈로우.
- 우하단 상시 그림 힌트(키캡+동작, 글자 없음). Esc 등 허용 집합 밖 키 배정 금지(단 기존 컨벤션 확인 시 그것을 따름).
- 모바일(390×844): 하단 컨트롤 밴드(가속/브레이크 레버 ≥64px, 중앙 액션 ≥88px, 뷰 ≥44px, 나가기 ≥44px).

## 3. 시작 시퀀스·온보딩

1. 기관사 모자 씌워짐 + "기관사 모자, 준비 완료!" + 경례. 첫 화면은 운전실(1인칭). 오디오 언락은 이 오버레이의 첫 Space.
2. 첫 순항 10초 후: "숫자 삼(3)을 눌러 봐! 바깥에서 우리 기차가 보여!" + [3] 키캡 점멸 → "우와, 우리 기차다!". 다음 구간에서 [1]도 1회.
3. 뷰 키캡 아이콘(1=운전대, 3=기차 옆모습) 상시 HUD. 2회차부터 음성 생략.

## 4. 정차 메커니즘 — "4세도 반드시 성공" (무벌칙)

- 3중 안전망: ① 어시스트 속도 봉투 `vmax(d) = min(300, 12·√d)` km/h 소프트 클램프(고정 수식만, 적응형 금지) ② 딱 멈추기: 정차 존(승강장 120m) 진입을 사건화(차임+손바닥 아이콘+경적 비활성), 이후 Space = 속도 무관 부드러운 정지 ③ 오버런 자동 보정: correcting phase, "어이쿠~" + 스프링 이징 복귀, 별 1개 항상 지급.
- 별: 마커 중심 ±10m ⭐⭐⭐ / ±25m ⭐⭐ / 그 외 ⭐. 감점 없음. ⭐⭐⭐ 연출(전원 점프+색종이+팡파르)이 오버런 개그보다 확실히 크다. 오버런 개그는 2회째부터 감쇠. MAX_FLASH_PER_SEC = 3.

## 5. 승객 탑승 — 능동적 수 세기 놀이

- Space 1회 = 친구 1명 탑승(폴짝+번호 크게+세기 음성 "하나!" "둘!"…). 세기는 그 역에서 탄 인원(역당 3~6명).
- 무입력: 5~6초 힌트 → 10초부터 자동 탑승(0.8초 간격), 아무 때나 Space로 복귀.
- 마지막 승객 직후 1.2초 입력 잠금("○명 탔어요!" 합계) 후 문 닫기 활성. 문 닫기: 6초 프롬프트, 12초 자동.
- 탑승 누적: 3인칭 객차 창문에 전신 스프라이트 축소 배치, 1인칭은 미니 패널 오버레이.
- 승객 구성: 기본 1~12번 역 순서 분산(3/3/3/3) + 게스트 13~99 중 2~3명 시드 추첨 + 특별 큰 손님 30/50/70/100 중 1명(등장 역 추첨, 예고 이벤트+개그 탑승+명명 라인 "와, 백이 왔어요!"). 판당 총 15~17명. 시드는 여정 시작 시 고정.
- "만난 친구" 누적 기록(localStorage) + 종착 요약 "처음 만난 친구" 배지. 100칸 풀 앨범 UI는 v2.

## 6. 두 개의 뷰 — 하나의 시뮬레이션

- `ktx-sim.mjs` 순수 시뮬(DOM 0줄): SimState{x, v, notch, segIndex, phase(departing|cruising|approaching|stopped|boarding|correcting), doors, boarded[], activeEvents[], stars[], rngSeed, idleTimer}, tick(state, input, dt=1/60 고정 스텝) → 프로젝션 뷰 2개(cab/side)가 읽기 전용 렌더.
- 1인칭 운전실: 침목 stroke-dasharray+dashoffset(v 비례), 전신주 노드 풀 2~3개 스케일업, 원경 미세 시차, 속도 풍선 스프라이트 경로 1개. 계기판(하단 1/3): 초대형 속도계 숫자(50/100/…/300 마일스톤 확대+음성, 색+크기 이중 부호화), 노치 레버, 문 램프, 다음 역 그림 배지, 정지 거리 그림 게이지(5칸). 1인칭 전용 재미 3개(속도 풍선, 터널 실내등, 비 와이퍼).
- 3인칭 측면: srt-journey 사이드 스크롤 계승, 열차 좌 1/3 고정 + 배경 3~4 레이어 패럴랙스, 4량 코드 SVG, 창문 탑승 누적, 정지 마커.
- 프레임 예산: transform/opacity만, per-frame DOM 생성 금지, 동시 애니메이션 노드 ≤40. reduced-motion: 전방 광류 정지, 속도감은 숫자+사운드로.

## 7. 이벤트 10종 (고정 6 + 랜덤 4)

고정: ① 쌩쌩 300 직선(수서→동탄, "삼백!" 대축하) ② 강 건너기(금강, 경적→오리) ③ 터널 메아리(경적 메아리, 3회에 박쥐) ④ 도심 천천히 존(속도 풍선 150, 봉투와 동일 메커니즘) ⑤ 바다+갈매기(동대구→부산, 경적→갈매기 편대) ⑥ 특별 승객 예고.
랜덤 풀 4종에서 3 추첨(교행 열차·비→무지개·눈·소 떼) → 매판 1종 미등장. 접근 구간(>0.8) 미발동, 시그니처 ±15% 간격, 시드 결정성. 10종 중 7종 경적 응답.

## 8. 스톨 감시·중도 이탈

- 전 phase 유휴 감시: 6초 그림 힌트 / 12초 자동 어시스트(크리프 출발·자동 브레이크·자동 탑승·자동 문). 아이 입력 시 즉시 반환. 테스트 불변식: "임의 유한 입력 후 입력 0이어도 유한 시간 내 종착 도달".
- 중도 이탈 무손실: 즉시 별 정산 + 만난 친구 유지 + 역 단위 체크포인트(이어타기 그림 2택).

## 9. 사운드·음성

- WebAudio 절차 합성(자산 0): 도미솔도 차임, 2음 경적(터널 delay 메아리), 속도 비례 바퀴 루프, BGM 루프 2(주행/정차). 경적 연타 소프트 리미트.
- 음성 우선순위 3단: P1 안내(경적 -12dB 덕킹) > P2 세기/칭찬 > P3 이벤트 리액션(드롭 가능). `ktx-voice.mjs` 순수 큐.
- 신규 보이스 ~30라인 + 역명 5종(역명은 문장 끝 배치, 조사 분기 제거). 음성 누락 폴백: 차임+픽토그램만으로 진행.

## 10~12. 난이도·홈·재플레이

- 난이도 축 없음(난이도 UI 숨김, 인자 무시). 어려움 흡수는 고정 어시스트가 전담.
- 홈 통합: 가산 원칙(기존 키·음성·테스트 무변경). M0 감사로 키맵 확정 후: 미사용 숫자키 있으면 배정(후보 0), 없으면 방향키+Space만. 홈 ↓=앨범 기각.
- 재플레이: 승객 시드 변주 + 만난 친구 기록 + 별 30개 KTX 스킨 해금 + 매판 랜덤 1종 미등장.

## 13~15. 파일·테스트·마일스톤

- 신규 10파일 ≈ 2,000 LOC (ktx-game 350, ktx-sim 250, ktx-route 120, ktx-events 150, ktx-passengers 150, ktx-voice 120, ktx-view-cab 300, ktx-view-side 250, ktx-audio 200, parallax 100).
- 신규 테스트 ≈ 60 (sim 18, route 8, events 10, passengers 10, voice 7, keys 7, 홈 확장).
- 마일스톤: M0 저장소 감사(착수 게이트) → M1 운전실 뷰 프로토(디리스크) → M2 순수 코어 → M3 뷰·컨트롤러 → M4 오디오·보이스 → M5 홈 통합·메타 → M6 마감(reduced-motion·접근성·QA).

## 16. v1 범위 선언

포함: 위 전부. v2+: 100칸 앨범, 서울발 KTX 노선, 야간·노을 이벤트, 하차 시뮬, ←/→ 둘러보기, 짧은 여행, 경적 연주 모드. 비목표(영구): 실제 시각표·신호·연료·지연·감점·실패 화면.
