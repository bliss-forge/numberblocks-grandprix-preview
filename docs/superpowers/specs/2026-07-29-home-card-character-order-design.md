# 홈 카드 캐릭터 번호 정렬 설계

## 목표

홈 화면의 1~5 게임 카드에 표시되는 숫자와 숫자블록 친구를 같은 번호로 맞춘다.

## 확정 매핑

| 카드 | 게임 | 캐릭터 자산 |
| --- | --- | --- |
| 1 | 몇 개일까? | `assets/characters/one.png` |
| 2 | 더하기 합체 | `assets/characters/two.png` |
| 3 | 빼기 블록 | `assets/characters/three.png` |
| 4 | 곱하기 블록 | `assets/characters/four.png` |
| 5 | 안전한 길찾기 | `assets/characters/five.png` |

## 구현 범위

- `index.html`의 홈 카드 이미지 경로만 변경한다.
- 카드 순서, 번호 배지, 문구, 배경색, 크기, 키보드 단축키는 유지한다.
- 기존 캐릭터 자산을 재사용하며 새 이미지는 만들지 않는다.
- 후속 시각 리디자인은 Claude가 맡을 수 있도록 루트 `CLAUDE.md`에 프로젝트 제약과 검증 기준을 기록한다.

## Claude 리디자인 인계

- Claude의 작업 범위는 홈 화면 시각 리디자인이며 게임 규칙, 음성, 안전길 로직은 변경하지 않는다.
- 홈 카드 순서와 단축키는 `1~5`를 유지하고 각 카드에는 같은 번호의 캐릭터를 표시한다.
- 기존의 평면 2D 숫자블록 친구 자산을 재사용하며 입체 스타일로 바꾸지 않는다.
- PC 1280×720과 모바일 390×844에서 잘림과 가로 스크롤이 없어야 한다.
- 변경 전후 전체 테스트와 두 화면 크기의 브라우저 캡처를 요구한다.

## 검증

- 정적 계약 테스트에서 카드 1~5의 이미지 경로가 각각 같은 번호의 자산인지 확인한다.
- 테스트가 기존 잘못된 매핑에서 실패하는 것을 확인한 뒤 이미지 경로를 수정한다.
- 전체 테스트와 1280×720 홈 화면 브라우저 확인을 실행한다.
