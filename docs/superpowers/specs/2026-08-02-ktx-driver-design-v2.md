## 0. 한 줄 컨셉 (초안 유지)

"오늘은 네가 기관사야." 기관사 모자를 쓰고 경례한 뒤, 수서에서 부산까지 직접 몬다. 역마다
넘버블럭스 친구들이 줄 서서 기다리고, Space 한 번에 한 명씩 태우며 함께 센다. 게임은 시종일관
아이를 "기관사님"이라 부른다.

## 1. 노선·열차·코어 루프

- **노선**: 수서 → 동탄 → 대전 → **대구** → 부산 (5역 4구간). 기존 SRT 게임 `SRT_STATIONS`를
  import(역명 단일 원본) — 표기·음성(`srt-station-daegu` 등 실존) 일관. [협회 만장일치]
- **열차 2택을 처음부터**: 시작 화면에서 ←/→+Space로 **SRT(자주색) / KTX(파란색)** 선택.
  해금 아님 — 사용자 원문이 "KTX/SRT"이고, 기차를 아는 아이는 파란 기차를 찾는다(4세 옹호 지적).
  차이는 차체 색 SVG 파라미터 + 경적 음색 변주뿐. 초안의 "별 30개 해금"은 삭제. [조정자 재정 ①]
- **구간 60~80초**(첫 구간 ~70초), 정차·탑승 ~30초×4, 피날레 40초 → **판 6.5~7.5분**.
  첫 별·첫 탑승 세기가 개시 90~100초 안에 온다. (초안 70~100초는 판 9분 산술 모순 — 협회 폐기)
- 루프: [수서 탑승] → 문 닫기 → ↑로 출발 → [주행: 배경 아크 + 이벤트 + 경적 놀이 + 마일스톤] →
  도미솔도 차임 "잠시 후 도착!" → [접근·정차: 3중 어시스트 + 별 1~3] → 문 열기 → [탑승 세기] → 반복.
- 종착 부산: 전원 하차 2단 세기 피날레(일반 친구 세기 → "그리고... 백!") + 오늘 만난 친구 요약 +
  **4정차 모두 ⭐⭐⭐면 "퍼펙트 기관사" 칭호 연출**(세션 내, 기존 cheer 음성 재사용) [7세 옹호 신설].

## 2. 배경 = "하루의 여정" 아크 (사용자 요구 4종 전부 v1)

| 구간 | 시간대·배경 | 고정 이벤트 |
|---|---|---|
| 수서→동탄 | 아침 도심 → 들판 | 쌩쌩 300 직선("삼백!" 대축하) |
| 동탄→대전 | 낮 들판·**강**(금강) | 강 건너기 — 경적에 오리 응답 |
| 대전→대구 | 노을 → **밤 산·터널** | 터널 메아리(실내등 점등) + 별·달 하늘 |
| 대구→부산 | 새벽 → **바다 해돋이** | 갈매기 편대 — 경적에 답례, 피날레로 연결 |

- 구현: 구간별 환경 밴드 사전 렌더 + 진행률 경계에서 opacity 크로스페이드 1.5s.
  지하철 `trainSceneSvg`의 환경 3종 switch를 6종(들판/강/터널/바다/밤/도심)으로 확장한 순수 함수.
  밤은 필터가 아니라 전용 팔레트 레이어(그라디언트·필터 금지 준수). [공학 렌즈 E4]
- **공포 회피 조항**(4세 옹호): 밤 팔레트는 별·달·창문 불빛의 아늑한 톤. 박쥐는 아이가 경적
  3연타로 스스로 부른 경우에만, 귀여운 실루엣으로. 밤 구간 정차·탑승 화면은 승강장 조명으로 밝게.
- 랜덤 이벤트: **풀 2종(교행 열차·소 떼)에서 매판 1종**이 구간 2 또는 3에 등장. 비→무지개·눈은 v2.
  [조정자 재정 ③ — 범위 렌즈 "전량 삭제"와 7세 옹호 "유지"의 절충]

## 3. 조작 (숫자키+방향키+Space 불변식)

| 키 | 주행 | 접근(존 진입 후) | 정차·탑승 |
|---|---|---|---|
| ↑ 홀드 | 가속 (**놓으면 속도 유지** — 코스트 순항) | 가속(봉투 클램프) | 문 닫힘 상태면 출발 |
| ↓ 홀드 | 브레이크 | 브레이크 | 무동작+뿅 |
| Space | 경적(항상 반응 보장) | **딱 멈추기**(무장 구간에서) | 문 열기 → 1명 태우기 → 문 닫기 |
| 1 / 3 | 운전실 / 바깥 뷰 (repeat 무시, 400ms 쿨다운, 크로스페이드) | 동일 | 동일 |
| Escape | **홈으로** (기존 전역 컨벤션 그대로 — 초안의 "0키 2초 홀드" 삭제) | 동일 | 동일 |
| 나머지 숫자 | 무동작+뿅 | 동일 | 동일 |

- **코스트 유지**: ↑를 놓아도 감속하지 않는다(감쇠 0). 감속은 ↓와 어시스트 봉투만.
  4세가 6분 홀드를 강제당하지 않고, 경적·뷰 전환에 손이 자유로워진다. 초안의 미정의를 확정.
  "노치 래치(탭=단수)"는 탭/홀드 판별 모호성으로 기각. [공학 회의론 kill 유지]
- phase 전환 직후 250ms 입력 스왈로우, 키 리핏 무시(keydown/keyup 추적) — 초안 유지.
- **v1은 PC 1280×720 전용.** 모바일 컨트롤 밴드는 codex 분담(기확립 방침).

## 4. 정차 — 3중 안전망 + 난이도의 심장 (수치 확정)

1. **어시스트 봉투**: `vmax(d) = clamp(12·√d, 35, 300)` km/h.
   초안 `min(300, 12·√d)`의 치명 결함 수정 — 바닥 35가 없으면 ↑만 잡아도 마커에서 자동 정지되어
   별 변별과 딱 멈추기의 존재 이유가 동시에 소멸한다. [난이도 렌즈 must]
2. **딱 멈추기 2단 무장**: 존(120m) 진입 = 차임+손바닥 아이콘+경적 비활성. **마커 40m 이내부터
   무장** — 그 전에 누르면 크리프(35km/h) 전환+"조금만 더~" 코칭(정차당 1회만, 반복 시 게이지
   강조만). 무장 구간에서는 어시스트가 접근 속도를 판정 속도 35km/h로 수렴시킨 뒤 판정 —
   ⭐⭐⭐ 실효 창 ≥2.0초를 구조적으로 보장. [난이도 P2 + 4세 옹호 fix]
3. **오버런 자동 보정**: 마커+30m(35km/h로 약 3.1초) 초과 시 correcting phase — "어이쿠~" +
   스프링 이징 복귀, 별 1개 항상. 개그 연출은 2회째부터 감쇠, ⭐⭐⭐ 연출이 항상 더 화려하다.

**별 판정**: Space keydown 시점에 벽시계로 시뮬 재동기 후 예측 정지점 계산(지하철 폴짝 판정과
동형) — 판정 정밀도는 틱(150ms)이 아니라 벽시계. 마커 ±10m ⭐⭐⭐ / ±25m ⭐⭐ / 그 외 ⭐.

**연령별 목표 성공률(스펙에 박제, M6에서 도하 실측 캘리브레이션)**:

| | 별1 | 별2+ | 별3(정차당) | 판 퍼펙트 4/4 |
|---|---|---|---|---|
| 4세 | 100%(설계 보장) | 85~95% | 30~45% | — |
| 6세 | 100% | ~100% | 65~75% | ~25% |
| 7세 | 100% | ~100% | 80~90% | 50~65% |

4세 별3 30~45%는 간헐 강화의 최적 지대(~1/3), 7세 판 퍼펙트 ~50%가 재도전 동기.

## 5. 탑승 — 능동적 수 세기 (게임의 심장)

- Space 1회 = 친구 1명 폴짝 탑승 + 번호 크게 + 세기 음성("하나!" "둘!"…) — **불변**.
- **승강장 대기줄 가시화**: 태울 친구들이 줄 서 있는 모습을 렌더, Space마다 줄이 하나씩 준다 —
  세기가 예측 놀이가 된다. 도착 직전 3인칭이면 줄이 미리 살짝 보인다. [재미 렌즈 must]
- **도레미 사다리**: 탑승 효과음이 승객 순서대로 도~라 상승 음계(역당 최대 6명과 1:1), 마지막
  승객 = 화음 + "○명 탔어요!". 역당 1명 micro-gag(모자 콜백·꾸벅 인사 2종) — 모션 변형만,
  소요 시간·세기 타이밍은 동일(추가 지연 0). [재미 P5 + 공학 fix]
- 무입력: 5~6초 힌트 → 10초 자동 탑승(**간격 1.1초** — 0.8초는 한국어 수사 음성과 충돌), 언제든
  Space로 복귀. 마지막 승객 후 1.2초 잠금. 문 닫기 6초 프롬프트/12초 자동.
- 승객: 기본 1~12 분산(3/3/3/3) + 게스트 13~99 중 2~3명 시드 추첨 + 큰 손님 30/50/70/100 중
  1명(역 추첨, 예고 이벤트, "와, 백이 왔어요!" 명명 선행). 판당 15~17명.
- **만난 친구 기록은 v1 유지**(localStorage, photo-hunt 주입 패턴 복제 — 실측 선례로 위험 낮음).
  종착 요약에 "처음 만난 친구" 배지. 풀 앨범 UI는 v2. [조정자 재정 ② — 7세 옹호 승]

## 6. 두 뷰 — 하나의 시뮬레이션

- 순수 시뮬 `ktx-journey.mjs`(DOM 0줄) + 두 뷰는 읽기 전용 프로젝션, **동시 마운트 + data-view
  토글**(파괴·재생성 금지).
- **1인칭 운전실(첫 화면·상품의 얼굴)**: 침목·전신주·배경 = **속도 티어 CSS 애니메이션**
  (data-speed-tier 0~5 양자화, ±10km/h 히스테리시스, 티어 전환 순간에만 JS가 위상 재동기 —
  폴짝 게임 `--hop-phase` idiom 그대로). 계기판: 초대형 속도계 숫자(마일스톤 확대+음성),
  문 램프, 다음 역 그림 배지, 정지 거리 5칸 게이지. 1인칭 전용 재미: 터널 실내등, 속도 풍선, 노치 연출.
- **3인칭 측면**: 열차 좌 1/3 고정 + 환경 밴드 스크롤, 4량 코드 SVG, **창문에 태운 친구 누적 +
  경적 시 승객 전원 폴짝**(태울수록 화려해짐 — 3인칭 전용 보상). 큰 손님은 창 한 칸 크게.
- **뷰 초대 반짝**: 고정 이벤트 때 반대 뷰 키캡이 볼거리 아이콘과 함께 점멸(갈매기=[3],
  터널 실내등=[1]). 판당 최대 3회, 접근·정차 존에서는 금지. MAX_FLASH_PER_SEC=3.
- 온보딩: 첫 순항 10초 후 "숫자 삼을 눌러 봐!"+키캡 점멸, 다음 구간 [1]. 2회차부터 음성 생략.

## 7. 경적 — "눌러서 재미없는 순간 0"

- 순항 중 어떤 경적도 최소 소반응 보장(까치 후두둑·허수아비 모자·창문 승객 폴짝 — 소품 풀 로테이션).
- 이벤트 오브젝트는 **연타 3단 에스컬레이션**: 오리 1회=한 마리 꽥 → 2회=줄줄이 도미노 →
  3회=경적 멜로디 답창. 소 떼·갈매기 동형. 4회+는 3단 반복(소프트 리미터와 정합).
- 순항 인터랙션 비트 간격 최대 15초(이벤트+마일스톤+베이스라인 합산) — 스톨 힌트(6초)보다
  세상이 먼저 말을 건다.

## 8. 스톨 감시·중도 이탈

- 전 phase 유휴 감시(6초 그림 힌트 / 12초 자동 어시스트) 초안 유지. 테스트 불변식:
  "임의 유한 입력 후 입력 0이어도 유한 시간 내 종착 도달"(퍼즈 포함).
- **세션 내 이어타기**: Escape로 나가면 여정 스냅숏을 메모리에 유지, 카드 재진입 시
  "이어서 탈까요? / 처음부터?" 그림 2택. localStorage 저장 없음(새로고침이면 소멸 — v2).
  [조정자 재정 ④ — "Escape 실수 한 번 = 7분 전손"(4세 옹호)과 영속 비용(범위·공학)의 절충]

## 9. 사운드·음성

- WebAudio 절차 합성은 **audio-manager.mjs 확장(+40~60줄)**: 도미솔도 차임, 2음 경적(터널
  delay 메아리), 속도 비례 바퀴 루프. **BGM은 v2**(코드베이스 최초 시도 리스크, 바퀴 루프가
  주행감 담당). 별도 ktx-audio.mjs 없음 — 합성의 집은 audio-manager.
- 음성 큐: 3단 우선순위+덕킹 폐기 → **단일 채널 + 대기 1슬롯**(P1 안내=즉시 교체, P2 세기·칭찬
  =대기 슬롯, P3 리액션=드롭). **예외: 탑승 세기 음성은 즉시 cancel-후-재생**(연타해도 모든
  숫자가 시작은 되게 — 수 세기 순서 완전성). `ktx-voice.mjs` 순수 큐 ~90 LOC.
- **재사용**: number-1~150 전량(세기·마일스톤 50/100/150), srt-station-4종, srt-depart/arrive
  계열, cheer-1~4(합창·칭호). **신규 녹음 13줄만**(HOTL 후 edge-tts 일괄): 수서 역명 1 ·
  이백/삼백 2(150 초과 공백 실측) · 온보딩 2 · 딱 멈추기 1 · 오버런 1 · 잠시 후 도착 1 ·
  큰 손님 예고 1 · 피날레 2 · 고마워요 기관사님 1 · 이어타기 1. **250은 시각 확대만, 음성 생략.**
  음성 누락 폴백: 차임+픽토그램으로 진행(차단 금지).

## 11. 조정자 재정 기록 (렌즈·반증 충돌 4건)

① **열차 해금 → 2택 기본 제공**: 범위·공학 "영속+해금 v2" vs 7세 옹호 "세션 간 장부 필요" vs
4세 옹호 "v1에 KTX 0은 사용자 원문 위반". 해금 시스템만 제거하고 열차 2택을 남기면 세 우려가
동시에 풀린다. ② **만난 친구 기록 유지**: 공학 회의론의 kill 논거는 "별 영속+스킨 해금+복원 UI
묶음 비용"이었는데 ①로 묶음이 해체됐고, photo-hunt 선례로 잔여 비용 ~60 LOC. 7세 재플레이
장부로서 가치가 비용을 넘는다. ③ **랜덤 2종 절충**: 전량 삭제(범위)는 7세 변주 0, 전량
유지(재미)는 밀도 초과 — 7세 옹호의 절충안 채택. ④ **이어타기 세션 내로**: 4세 옹호의
"Escape 실수=전손" 반증은 유효하나 localStorage 복원 UI까지는 과잉 — 메모리 스냅숏으로 충분.
